============================================================
           GESTICOM PRO - NOTICE D'INSTALLATION
============================================================

Bienvenue dans votre logiciel GestiCom Pro. 
Suivez ces étapes simples pour l'installation :

1. INSTALLATION (A faire une seule fois)
   - Faites un clic-droit sur le fichier : INSTALLER-PRO.bat
   - Choisissez "Exécuter en tant qu'administrateur"
   - Attendez la fin de l'opération.

2. LANCEMENT
   - Un raccourci "GestiCom Pro" a été créé sur votre Bureau.
   - Double-cliquez dessus pour ouvrir le logiciel.

3. EN CAS DE PERTE DE MOT DE PASSE
   - Lancez le fichier : REPARER-ADMIN.bat
   - Il remettra l'accès par défaut : admin / Admin@123

4. SUPPORT TECHNIQUE
   - Contactez GSN EXPERTISES GROUP pour toute assistance.
