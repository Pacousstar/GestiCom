# 🚀 Guide d'Installation GestiCom Pro (Déploiement Client)

Voici les étapes à suivre pour installer GestiCom Pro chez votre client, de la copie des fichiers jusqu'à la première vente.

### Étape 1 : Préparation du PC Client
1.  Copiez le dossier `INSTALLATION_GESTICOM` sur le disque dur du client (Recommandé : `C:\GestiCom-Portable`).
2.  Assurez-vous que le dossier `C:\gesticom` existe ou sera créé pour la base de données (le système s'en occupe généralement, mais vérifiez les droits d'écriture sur le disque `C:`).

### Étape 2 : Installation de GestiCom Pro (Le Moteur)
1.  Ouvrez le dossier d'installation.
2.  Cherchez le fichier **`INSTALLER-PRO.bat`**.
3.  **IMPORTANT** : Faites un clic droit sur le fichier et choisissez **"Exécuter en tant qu'administrateur"**.
4.  Une fenêtre s'ouvre, elle va tout configurer (Base de données, Service Windows, Raccourci) et se fermer.
5.  *Désormais, GestiCom tourne en arrière-plan comme un vrai logiciel professionnel !*

### Étape 3 : Premier Lancement et Activation Royale
1.  Ouvrez votre navigateur (Chrome ou Edge de préférence).
2.  Tapez l'adresse : **`http://localhost:3000`**.
3.  L'écran **"Activation Royale"** va apparaître immédiatement car le logiciel est neuf.
4.  **Action du Commercial** : 
    - Copiez l'**Identifiant Machine (HWID)** affiché sur l'écran.
    - Envoyez-le au DG DIHI pour recevoir la **Clé de Licence**.
    - Entrez la clé reçue et cliquez sur **"Activer le logiciel"**.
5.  Le logiciel se débloque instantanément. 🎉

### Étape 4 : Première Connexion (Admin)
1.  Vous arrivez sur la page de connexion.
2.  **Identifiants par défaut** :
    - Identifiant : `admin`
    - Mot de passe : `admin`
3.  Allez immédiatement dans **Paramètres** pour changer le nom de l'entreprise et les informations de contact du client.

### Étape 5 : Première Saisie de Données (Test de flux)
Pour vérifier que tout fonctionne :
1.  **Produits** : Créez un article d'essai (ex: "Article Test", Prix Achat: 1000, Prix Vente: 1500).
2.  **Stocks** : Faites une entrée de stock pour cet article (ex: 10 unités).
3.  **Ventes** : Allez dans "Nouvelle Vente" et vendez 1 unité.
4.  **Vérification Pro** : 
    - Allez dans **Rapports > Rentabilité**. Vous devez voir votre marge de 500 GNF/FCFA sur cet article.
    - Le stock doit être passé à 9 unités.

**Félicitations ! GestiCom Pro est opérationnel chez votre client.**
