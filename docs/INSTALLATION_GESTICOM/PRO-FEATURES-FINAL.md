# Walkthrough - GestiCom Pro : Service Windows & Licence Royale

J'ai finalisé l'implémentation des solutions "Pro" pour GestiCom, garantissant une discrétion totale du serveur et une protection premium du logiciel.

## 🛠️ Service Windows : Discrétion et Robustesse
- **Moteur Invisible** : GestiCom s'exécute désormais en tant que service système (`GestiCom-Server`). La fenêtre CMD noire n'est plus visible.
- **Auto-Démarrage** : Le serveur se lance automatiquement au démarrage de Windows, sans intervention humaine.
- **Installation Facile** : Ajout d'un fichier `INSTALLER-SERVICE.bat` pour configurer le service en un clic (mode admin requis).

## 🛡️ Système de Licence "Royale"
- **Blocage Premium** : Si la licence n'est pas activée, l'application est désormais totalement bloquée par un écran de sécurité élégant (effet glassmorphism).
- **Activation Simplifiée** : La page d'activation a été renommée "Activation Royale" et redessinée pour un aspect premium, idéal pour les démonstrations commerciales.
- **Harmonisation** : Suppression de toutes les bannières d'évaluation inesthétiques au bas de l'écran. L'ID machine (HWID) est facilement copiable depuis les écrans de blocage et de connexion.

## 📈 Rappel des Fonctions Pro Déployées
- **Rentabilité Produits** : Dashboard complet avec calcul de marge en temps réel.
- **Programme de Fidélité** : Cumul de points et remises automatiques configurables.
- **Flexibilité Temporelle** : Saisie des ventes à des dates antérieures.

## 📝 Guide pour les Commerciaux
1. Lancer l'application. Si elle est bloquée, copier l'**Identifiant Machine** affiché.
2. Obtenir la clé auprès de la Direction GSN.
3. Entrer la clé sur la page "Activation Royale" pour débloquer instantanément toutes les fonctionnalités du client.
